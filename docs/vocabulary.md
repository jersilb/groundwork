This file is a hard constraint, not a style guide. `scripts/lint-vocabulary.mjs` reads the **Never use** column and fails CI if any term appears in a tracked, non-exempt file. See `.vocabignore` for the narrow set of files allowed to name these terms as prohibitions.

## What is safe (not banned)

Generic strategic-planning vocabulary is fine — it predates and sits outside Paterson's marks: current reality, purpose, vision, values, core strategies, initiatives, priorities, review rhythm, renewal. The general assess → clarify → prioritize → align → review → renew arc is a standard planning skeleton (Drucker, Balanced Scorecard, OKRs) and is not proprietary.

## Maintaining this file

Add a term the moment anyone — Jeremy, a contributor, an AI session — encounters a new Paterson-specific name, whether from the manual (which never enters this repo) or from external research done safely (e.g., reading Paterson's public trademark filings, not their internal manual). Do not remove a term without Jeremy's explicit sign-off; this file only grows.
