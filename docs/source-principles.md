# Source Principles — Groundwork

**This file is written by Jeremy only. No AI session should add entries here.**

Per the build plan §2.3: the Paterson Group manual never enters this repository — not as a file, pasted text, a prompt, or a vector store. If Claude Code is ever handed manual content, it will refuse it and say why.

Instead, Jeremy extracts principles here: one line each, in his own words, describing the underlying *idea* rather than the manual's specific expression of it. Ideas, processes, and methods are not copyrightable; the manual's exact text and worksheet structure are.

## Acceptable entry

> "Diagnosis must precede goal-setting or teams set goals against a fantasy version of themselves."

This is a general planning insight in Jeremy's own words. It doesn't reproduce anything from the manual — it states a principle a competent facilitator could arrive at independently.

## Unacceptable entry

Anything that reads like it was lifted or lightly reworded from a manual page — a close paraphrase of a specific sentence, question script, scenario, or worked example. If an entry feels like "how do I reword theirs" rather than "what did I learn that I can state plainly," it doesn't belong here.

## How this file gets used

`curriculum-author` reads these principles when building segment specs (Phase 8). The question every exercise starts from is not "how do I reword theirs" but "what does a church leadership team actually need to figure out here, and what is the best way to get them there" — built from ministry-domain reasoning outward, never from the manual inward.
